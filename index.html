劳务狗狗

把繁琐的劳务支付流程，
整理成一条清晰、可执行的路径。

本地运行 · 一次录入 · 多端复用

做一笔劳务支付，
为什么总感觉流程很长？

因为它不是一个动作，而是一串动作。
从最开始收集人员信息开始，一笔劳务通常要经过：

  • 钉钉劳务人员录入
  • 钉钉任务下达
  • 通知劳务管理员发起确认
  • 税务确认
  • 用友表头核对
  • 用友多张表格导出
  • 部分场景下的签署文件或国外信函处理

单独看，每一步都不算难。
但连起来之后，就会形成大量重复整理、复制粘贴、模板拼接和导出核对的工作。

不是某一步特别复杂，
而是整条链条都在消耗注意力。

真正消耗时间的，
往往不是判断，而是重复。

在实际工作里，同一批劳务信息会不断重复出现。同一个姓名、证件号、银行账号、项目名称、核算月份，会被不同系统和不同模板反复使用。

与此同时，这些信息本身并不总是整齐的：

  • 初始 Excel 来源不统一
  • 表头命名不一致
  • 一个批次可能有多个人
  • 国内居民和国外非居民规则不同
  • 人民币、外币、税前、税后、价税、不含税口径并存

流程没有被组织起来。
信息也没有。

所以，劳务狗狗要解决的，
不是某一个页面，而是这条流程。

劳务狗狗是一个本地运行的劳务支付辅助工具。它的核心目标不是取代现有系统，而是把进入钉钉、税务确认、用友导出之前的准备工作先整理成一个稳定结构。

它主要做三件事：

  • 统一整理批次和人员数据
  • 提供钉钉录入用的可复制工作台
  • 生成税务确认和用友侧需要的结构化导出文件

先把信息理顺，
后面的流程才会顺。

先有一个批次，
再有这一批人。

劳务狗狗把这件事拆成两个核心对象：

支付批次

对应一个项目、一个核算月份、一次支付。

劳务人员

对应这一批次下的每一个人，包括主信息、结算信息、税务与导出信息。

这样拆开之后，很多原来混在一起的动作就有了明确边界：

  • D1、D2 按人处理
  • DQ、SQ、Y、H 按批次处理

流程一旦分层，
复杂度就会下降。

第一步，不是去填系统，
而是先把信息收拢。

在劳务狗狗里，真正的起点是 S 一次性录入。这个页面是整套流程的主数据页，用来统一维护：

批次头信息
人员主信息
人员结算信息
税务与导出信息

它支持两种方式进入：手工录入 + Excel 导入。这样做的意义在于，后面的钉钉录入、税务确认、用友导出，都不再各自重新整理一遍数据。

不是把表搬进来，
而是把信息收进来。

不是所有人的 Excel，
都长得一样。

这也是实际工作里最常见的问题。表头名称和字段顺序往往都不统一。

所以劳务狗狗在导入时做的不是简单"读表"，而是：

  • 识别 sheet
  • 判断表头行
  • 自动匹配字段
  • 支持手工修正映射
  • 对手机号、金额、日期等基础数据做清洗

表格可以不统一，
但结构必须统一。

到了钉钉，
不需要再把同一份信息重新想一遍。

有些推进动作，
不应该卡在"我该怎么说"上。

在 DQ 页面里，系统会按当前批次自动生成发给劳务管理员的通知语。

"您好，XX项目 2026年4月批次劳务现已整理完毕，共3人，币种人民币，请协助发起确认流程。项目方：XX公司。"

一键复制，发送即可。

一句话也能被整理好，
流程就更容易往下走。

到了财务确认这一步，
不应该再从零整理一次。

流程的最后几步，
终于也被接住了。

如果一个工具要长期使用，
它就不能只会"跑一次"。

劳务狗狗当前已经支持一组运行期可维护能力：

批次管理
项目名称维护
项目方维护
劳务标准管理
文件模板维护

项目名称可以标准化绑定，降低用友导入失败概率。劳务标准可以关联工作内容、价格范围、核算单位。

不是把规则焊死在代码里，
而是把一部分规则沉淀成可维护资源。

有些工具，
越靠近使用现场，越有效。

劳务狗狗目前的形态：

🏠 本地运行 · 本地保存 · 离线可用
🔌 不依赖真实钉钉 API · 不依赖真实用友 API
🚫 没有登录 · 没有后端 · 没有多用户系统

先把这一段最真实、最高频、最容易出错的流程做顺，比一开始就做成一个大而全的平台更有意义。

离现场越近，
工具越容易真正帮上忙。

劳务狗狗真正改变的，
不是某一张表，而是整个过程里的节奏。

过去
收表 → 整理 → 复制 → 再整理 → 再复制 → 再核对 → 再导出
现在
录入 → 确认 → 输出 → 推进

它并没有改变制度本身，也没有取代现有系统。它做的，是把原本散落的信息和动作组织起来。

少一次重复，就少一次出错。
少一次出错，就少一次返工。

从信息散落，
到流程成形。

劳务狗狗是一款面向项目经理的本地劳务支付流程助手。它围绕一条真实工作链条展开：一次录入，多端复用，覆盖钉钉人员录入、任务下达、LM 确认通知、税务确认表、用友多表导出与外籍信函生成。

它没有试图替代一切。它只是先把最值得被梳顺的这一段，真正梳顺。
